OPERA VIVA - INSTALLATORE WINDOWS (SETUP EXE)
Created by Marzio Sparla
===================================================================

DESCRIZIONE:
Questo file di installazione (OperaViva_Setup.exe) installa l'applicazione 
OperaViva direttamente nel sistema Windows del tuo computer/laptop.

VANTAGGI DELLA VERSIONE INSTALLABILE:
- Crea automaticamente l'icona sul Desktop e nel Menu Start di Windows.
- Registro di disinstallazione pulito da "Pannello di controllo / App installate".
- Aggiornamenti gestiti e percorsi applicativi dedicati.

COME INSTALLARE:
1. Fai doppio clic direttamente sull'icona della tavolozza d'artista "OperaViva_Setup.exe".
2. Segui i passaggi guidati della procedura d'installazione.
3. Al termine, l'archivio d'arte OperaViva comparirà sul tuo Desktop e nel Menu Start con la sua icona!

REQUISITI DI SISTEMA:
- Windows 10 o Windows 11 (64-bit)
- Nessuna connessione internet richiesta: il programma e il database funzionano 100% offline!
- 100% Gratuito: nessuna versione di prova, nessuna scadenza, opere illimitate.
