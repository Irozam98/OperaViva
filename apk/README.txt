DESCRIZIONE:
Questo file (OperaViva.apk) è l'applicazione nativa per dispositivi mobili 
Android (smartphone, tablet, display da galleria).

VANTAGGI DELLA VERSIONE MOBILE ANDROID:
- Interfaccia ottimizzata per il tocco (touch-friendly), visualizzazione compatta e dettagliata.
- Accesso rapido alla fotocamera dello smartphone per scattare direttamente foto alle opere e importarle nell'inventario.
- Editor fotografico integrato utilizzabile con le dita (livella angolare, ritaglio proporzionale, correzione luce/colore, cornici virtuali dorate/legno, timbro d'autore).
- Generazione immediata e condivisione dei Certificati di Autenticità in PDF / stampa.

COME INSTALLARE SU SMARTPHONE O TABLET ANDROID:

METODO 1 (Più semplice - WhatsApp / Telegram / Email / Google Drive):
1. Invia il file "OperaViva.apk" al tuo smartphone (es. tramite WhatsApp Web a te stesso, Telegram "Messaggi Salvati", Google Drive o cavetto USB).
2. Sul telefono tocca il file "OperaViva.apk".
3. Se richiesto, acconsenti all'opzione "Consenti l'installazione da questa origine" (Impostazioni > Sicurezza > Installa app sconosciute).
4. Tocca "Installa" e poi "Apri".

METODO 2 (Tramite cavetto USB e computer):
1. Collega il telefono al PC con il cavo USB e abilita il "Debug USB" nelle Opzioni Sviluppatore del telefono.
2. Fai doppio clic sul file "Installa_su_Smartphone_via_USB.bat" presente in questa cartella.

REQUISITI:
- Smartphone o Tablet con Android 8.0 o superiore.
- Funzionamento 100% offline, nessun abbonamento o connessione obbligatoria.
- 100% Gratuito: nessuna versione di prova, nessuna scadenza, opere illimitate.
